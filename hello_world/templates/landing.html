Szybki Dostęp

🔑 Admin Panel

URL: http://localhost:8000/admin/

Username: admin

Password: admin123

🌐 API Root

URL: http://localhost:8000/api/

Authentication: Token-based

Format: JSON

🔐 Get Token

Endpoint: POST /api/auth/token/

Body: username + password

Header: Authorization: Token <token>

Przykłady Użycia API

🔓 Uzyskaj Token

curl -X POST http://localhost:8000/api/auth/token/ \ -H "Content-Type: application/json" \ -d '{"username":"admin","password":"admin123"}'

📋 Lista Eksperymentów

curl -H "Authorization: Token YOUR_TOKEN" \ http://localhost:8000/api/experiments/

🔍 Filtruj i Szukaj

curl -H "Authorization: Token YOUR_TOKEN" \ "http://localhost:8000/api/experiments/?status=ongoing"

📊 Raport Eksperymentu

curl -H "Authorization: Token YOUR_TOKEN" \ http://localhost:8000/api/experiments/1/summary/

🧬 Gene Expression Report

curl -H "Authorization: Token YOUR_TOKEN" \ http://localhost:8000/api/experiments/1/\ gene_expression_report/

📊 Results Report

curl -H "Authorization: Token YOUR_TOKEN" \ http://localhost:8000/api/experiments/1/\ results_report/

Szybki Start (5 minut)

  1. Zainstaluj zależności: pip install -r requirements.txt
  2. Migruj bazę: python manage.py migrate
  3. Załaduj dane: python populate_data.py
  4. Uruchom serwer: python manage.py runserver
  5. Otwórz przeglądarkę: http://localhost:8000/admin/
